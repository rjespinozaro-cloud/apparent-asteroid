# Texturas de la Tierra

Mapas usados por el planeta 3D de `/perfil/`.

Origen: ejemplos de three.js, `examples/textures/planets/`
(<https://threejs.org/examples/textures/planets/>), distribuidos con el
repositorio de three.js bajo licencia MIT.

- `earth_atmos_2048.jpg`: color del día.
- `earth_lights_2048.png`: luces nocturnas.
- `earth_clouds_1024.png`: nubes (mapa alfa).
- `earth_normal_2048.jpg`: normales.
- `earth_specular_2048.jpg`: mapa especular (océanos).
